# Vendor CRM

## Project Overview
Vendor CRM is a centralized application designed to manage vendors, purchase orders, contracts, inventory, invoices, payments, and vendor relationships.

## Technology Stack
- Frontend: React.js
- Backend: Java Spring Boot
- Database: MySQL
- API Testing: Postman
- Version Control: Git & GitHub

## Project Modules
1. Login & Authentication
2. Dashboard Overview
3. Vendor Management
4. Purchase Order Management
5. Contract Management
6. Product & Service Management
7. Inventory Management
8. Invoice & Payment Management
9. Vendor Performance Management
10. Vendor Communication
11. Reports & Analytics
12. Notifications
13. Settings & Administration
