# Vendor CRM – Backend

## Project Overview
Backend application for Vendor CRM, developed using Java Spring Boot and MySQL. Provides REST APIs for vendor management and all CRM modules.

## Technology Stack
- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- MySQL
- Maven
- Postman

## Project Modules
1. Login & Authentication
2. Dashboard Overview
3. Vendor Management
4. Purchase Order Management
5. Contract Management
6. Product & Service Management
7. Inventory Management
8. Invoice & Payment Management
9. Vendor Performance Management
10. Vendor Communication
11. Reports & Analytics
12. Notifications
13. Settings & Administration

## Database
MySQL

## API Testing
Postman
